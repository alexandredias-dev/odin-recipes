# odin-recipes

Um projeto de receitas simples criado para praticar as bases de HTML e navegação entre páginas como parte do currículo do The Odin Project.

## Sobre o projeto
Este site contém uma coleção de receitas fáceis de preparar, organizadas em uma estrutura de pastas para praticar a navegação de arquivos (links relativos) em HTML.

## Tecnologias utilizadas
- HTML5

## Como visualizar
Você pode acessar o projeto online através do link:
[https://alexandredias-dev.github.io/odin-recipes/](https://alexandredias-dev.github.io/odin-recipes/)

## Estrutura do projeto
- `index.html`: Página principal com a lista de todas as receitas.
- `recipes/`: Pasta contendo os arquivos individuais de cada receita.
